# Context7 Usage Guidelines

When researching external libraries, framework APIs (Next.js, FastAPI, React, SQLAlchemy, Pydantic, etc.), or specific version requirements:
- Use Context7 MCP tools to pull live, up-to-date documentation and code examples from official sources.
- Prevent API hallucinations by validating against real-time documentation fetched via Context7.
