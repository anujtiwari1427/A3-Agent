# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 2.4.x   | :white_check_mark: |
| < 2.4   | :x:                |

## Reporting a Vulnerability
We take the security of A3-Agent seriously. If you discover a security vulnerability:

1. **Do not create a public issue.**
2. Send a detailed report to the repository security maintainers or open a private GitHub Security Advisory.
3. Include reproduction steps, affected components, and potential impact.
4. The team will acknowledge receipt within 48 hours and coordinate a fix.
